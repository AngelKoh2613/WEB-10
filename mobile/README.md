# SecurePlan Mobile

Cliente Flutter de SecurePlan. El paquete Dart se llama `secureplan_mobile` y el nombre visible es SecurePlan.

El identificador nativo es `com.secureplan.mobile` en Android (`applicationId`, `namespace` y paquete Kotlin) y en iOS (`PRODUCT_BUNDLE_IDENTIFIER` de la aplicación y de `RunnerTests`). No se ha compilado un APK ni una aplicación iOS en esta máquina.

La aplicación incluye registro, inicio, cierre de sesión y la agenda con calendario. La URL de la API y la diferencia entre emulador, teléfono y escritorio están en [`../docs/Development.md`](../docs/Development.md).
